Teslap

software systems

A ride-pooling MVP for Dhaka. It matches overlapping ride requests, splits fares down to the paisa, and gives drivers a manifest to work from.

The difficult part was the last seat: two passengers might try to claim it at once. I used PostgreSQL row locking, idempotency keys and a database capacity trigger, then tested the race instead of trusting the happy path.

RAGTOP

retrieval & evaluation

A laptop recommendation pipeline built from multiple product sources, schema harmonisation, PySpark processing, embeddings and MinHash/LSH deduplication.

I compared five FAISS index types. On the exact-search comparison, HNSW recovered 84.7% of exact top-five results at 0.116 ms average query latency. On a separate 30-query labelled set, hit rate was 0.60 and precision@5 was 0.253.

Python · PySpark · FAISS · embeddings · MinHash/LSH

Probaho

multilingual NLP · capstone

A university-information chatbot for English, Bangla and Banglish, built as a team capstone project at East West University. It is the hybrid architecture (Rasa + RAG + LLM), one of six compared in our thesis. I designed and implemented the RAG pipeline (ingestion, retrieval and the LLM answer service) and contributed RAG data with two teammates; a fourth teammate designed the Rasa pipeline and its data.

অলীকবচন / Olikbochon

applied research

A Bengali-language hallucination detection system I built on my own. It combines lexical overlap, character-level TF-IDF, answer-key matching and cross-lingual NLI using mDeBERTa-v3.

I combined the signals with Logistic Regression and LightGBM, using a quantized 32B Qwen model as a judge. The pipeline reached 0.794 out-of-fold macro-F1 on the labelled sample.

Python · LightGBM · vLLM · NLI · TF-IDF

RepoQuest

developer tools

A guide for getting into unfamiliar codebases. Paste a public GitHub repository and it generates three developer quests, each with a goal, steps, success criteria and links to relevant source files and real issues.

An n8n workflow gathers the evidence (metadata, README, file paths, open issues) and Gemini writes the quests. The response is validated, including the source-file paths, before it reaches the UI. It is a working prototype, and quest quality depends on how much evidence a repository offers.

Next.js · TypeScript · n8n · Gemini API · GitHub REST API

A Comparative Study on Domain-Specific Multilingual Chatbots Developed Using Different Approaches

My undergraduate thesis at East West University, done with teammates. It compares six chatbot architectures on the same university knowledge base in English, Bangla and Banglish: Rasa, an SLM, RAG + SLM, RAG + LLM, Rasa + RAG + LLM, and Rasa + RAG + SLM. I built two of them: Probaho (the Rasa + RAG + LLM hybrid) and Shombit (RAG + LLM only). Defended before the faculty panel at the final capstone stage (Capstone C).

retrieval-augmented generation · small language models · evaluation · code ↗

in progress

SC-GRC: routing between small and large fine-tuned models

A follow-up to the thesis, unpublished. I fine-tuned Qwen2.5-3B and 7B with QLoRA on about 10,900 English, Bangla and Banglish question–answer pairs. A router then decides, query by query, whether the small model’s answer is good enough or the larger model should answer. It uses self-consistency across sampled answers and retrieval signals, with a semantic cache. The benchmark has 333 queries (111 questions in three languages, across 37 categories) and compares five systems.

I am re-validating the experiments before reporting results.

QLoRA · adaptive routing · self-consistency · semantic caching · multilingual evaluation

early-stage

Human-Centric Recommendation Systems for Research Discovery

I’m exploring how recommendation models can support discovery on Researchar, a live platform for researchers. The planned evaluation compares a candidate recommender with baseline approaches using both in-platform feedback (satisfaction, trust and perceived relevance) and behavioral signals such as click history. The focus is whether recommendations improve user experience alongside system performance, rather than relying on offline ranking metrics alone.
