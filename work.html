RepoQuest

developer tools

Paste a public GitHub repo and get three developer quests with steps, success criteria and links to real source files and issues. A working prototype.

how it works

A guide for getting into unfamiliar codebases. You paste a public GitHub repository and it generates three developer quests, each with a goal, steps, success criteria and links to relevant source files and real issues. An n8n workflow gathers the evidence and Gemini writes the quests; I validate the response, including source-file paths, before it reaches the UI. It is a working prototype. Built with Next.js, TypeScript, n8n and the GitHub API.

how it works

A ride-pooling MVP for Dhaka that matches overlapping ride requests, splits fares down to the paisa, and gives drivers a manifest to work from. RAGTOP

retrieval & evaluation

A laptop recommendation pipeline over 1,960 configurations. HNSW recovered 84.7% of exact top-five results at 0.116 ms per query.

how it works

A laptop recommendation pipeline built from multiple product sources, with schema harmonisation, PySpark processing, embeddings and MinHash/LSH deduplication. I compared five FAISS index types: HNSW recovered 84.7% of exact top-five results at 0.116 ms average query latency. On a separate 30-query labelled set, hit rate was 0.60 and precision@5 was 0.253. Built with Python, PySpark and FAISS.

Olikbochon

applied research

A Bengali hallucination detector I built on my own, combining lexical, NLI and LLM-judge signals. It reached 0.794 out-of-fold macro-F1.

how it works

A Bengali-language hallucination detection system I built on my own. It combines lexical overlap, character-level TF-IDF, answer-key matching and cross-lingual NLI (mDeBERTa-v3), merges the signals with Logistic Regression and LightGBM, and uses a quantized 32B Qwen model as a judge. It reached 0.794 out-of-fold macro-F1 on the labelled sample. Built with Python, LightGBM and vLLM.
